# Description structure

Write in this order. Keep each part short.

1. **Hook (1-2 lines).** The problem or result in the buyer's words. No hype.
2. **Who it is for (1-2 lines).** One specific reader, plus one line on who it is not for.
3. **What you get.** A short bullet list of the exact files, formats and quantities. Only what the seller listed.
4. **Benefits.** Two to four outcomes tied to the problem. Phrase as what the buyer can do, not as promises.
5. **How it works.** Three to four numbered steps if the product is a tool, prompt or template.
6. **Requirements.** What the buyer needs. See the pricing file for the block format.
7. **Licence note.** One line, e.g. "Use it for yourself and your clients. No resale or redistribution."
8. **Call to action.** One line telling the buyer what to do next.
9. **Add-on block** (optional). See addon-blocks.md.

## Rules
- Use the product name exactly as given.
- Avoid: revolutionary, game-changing, ultimate, guaranteed, secret.
- No fake scarcity, fake reviews or invented numbers.
- If a fact is missing, leave `[BRACKETS]`.
- Add a one-line disclaimer only if the product makes health, money or legal claims.
