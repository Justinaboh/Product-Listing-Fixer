# Add-on blocks

Ask the seller which type they want, and the other product's name. Leave the link as a gap.

| Type | Use when | Placement |
|---|---|---|
| Upsell | A higher tier or bigger product that adds to this one | End of description, and on the checkout page |
| Downsell | A cheaper option for someone who hesitates | After the price, or on an exit screen |
| Cross-sell | A related product that solves a neighbouring problem | End of description |

## Block templates
**Upsell:** Want more? **[PRODUCT NAME]** adds [WHAT IT ADDS, from the seller]. [PASTE LINK HERE]
**Downsell:** Not ready for the full version? Start with **[PRODUCT NAME]**. [PASTE LINK HERE]
**Cross-sell:** Pairs well with **[PRODUCT NAME]**, which helps with [RELATED PROBLEM, from the seller]. [PASTE LINK HERE]

## Rules
- Use the product name exactly as given.
- One add-on per listing unless the seller asks for more.
- Do not describe benefits the seller did not state.
- Keep `[PASTE LINK HERE]` unless the seller supplies the real link.
