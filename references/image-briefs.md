# Image briefs

Three optional images. Produce only the ones the seller asked for. Use the same product name, palette and style across all of them so they look like one set.

## Colours and style
Do not ask. Use the seller's colours or style if they volunteered them; otherwise use a clean, neutral palette (soft greys, white, one accent colour) and simple modern type.

## 1. 3D box mockup
- Product presented as a premium packaged product: a 3D box, or a book, tablet, laptop or phone mockup that fits the product type.
- Three-quarter or isometric angle, soft realistic lighting and shadows.
- Show the exact product name and a short subtitle.
- Show only what the seller listed. No fake bonuses, badges or features.

## 2. Store cover
- Product name prominent, one short benefit line, strong hierarchy.
- Readable as a small thumbnail as well as full size.
- Wide landscape, matching the box mockup's look.

## 3. Promo banner
- Wide landscape. Product name, main value line, one short supporting line.
- Clean negative space, one focal point, little text.
- Easy to crop for the platform and for social media.

## Checks before presenting
- Product name identical on every image and spelled correctly.
- Every word in the image is spelled correctly. If not, redo the image.
- Nothing shown that the seller did not list.

## Prompts (always include)
For every requested image, give one ready-to-paste prompt, whether or not an image was generated. The seller can use it to recreate the image in another tool if they do not like the result.

Each prompt contains: the exact product name and subtitle text, what to show, angle and lighting, the palette used (the seller's or neutral), and the wide format. Use the same wording the image was made from, so results are close.

If no image tool is available, give the prompts alone and label them "image prompts, not finished images".

## Delivery format per image
1. The image (if generated)
2. "Prompt to recreate this elsewhere:" followed by the prompt in a code block
