# Platform notes

Use these to tailor output A. **None of this is verified against live platform documentation. Mark every limit "verify before publishing".** If the AI tool can search the web, check the platform's current seller help pages first.

## How to tailor
Ask where the seller sells, then adjust:
- **Length and layout.** Short and scannable for marketplaces; fuller sales-page copy for the seller's own site.
- **Field names.** Use the platform's own terms (e.g. title, short description, details, tags) and leave `[BRACKETS]` where the seller must check a limit.
- **Licence and requirements.** Put them where buyers see them before paying.
- **Add-on block.** Place it where the platform lets sellers link to other products.
- **Images.** Note that each platform has its own image sizes; give the seller the image at a generous size and say to crop to the platform's current spec.

## Platform profiles (general, unverified)
| Platform | Typical style |
|---|---|
| Gumroad | Single product page; long-form description; tiers via versions; cover and thumbnail images |
| Etsy | Marketplace; short title with keywords; tags; digital downloads need clear "what you receive" |
| Shopify | Own store; product page copy plus short card text; room for FAQ |
| Payhip, Lemon Squeezy | Similar to Gumroad; check each platform's tier and licence options |
| Own site | Full sales-page structure; no platform limits, but keep it scannable |
| Other | Ask the seller for the platform's field list and limits |

## Rules
- Never state a platform's fees, limits or policies as fact.
- If the seller gives a platform's limit, use it.
